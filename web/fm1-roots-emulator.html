Télécharger le paquet de test ↗

Clique sur Start dans l’écran pour démarrer le son. L’émulateur reproduit le processeur, l’écran, les touches, les encodeurs et l’audio du FM1. Il exécute notre paquet compilé, pas une synthèse de démonstration. Cela reste une émulation logicielle : le comportement électrique et les périphériques physiques doivent encore être validés sur le vrai appareil.
